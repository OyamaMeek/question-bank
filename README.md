# CET Question Bank

大学英语四、六级（CET-4 / CET-6）历年真题资料库，按考试级别、年份和考试月份整理，集中收录试题、答案解析及听力音频，方便备考复习、限时练习与错题整理。

## 内容概览

仓库目前主要包含以下资料：

- CET-4（大学英语四级）历年真题
- CET-6（大学英语六级）历年真题
- 试题与答案解析（PDF、DOC、DOCX）
- 听力音频（MP3、M4A）
- 部分可复制、可搜索或适合打印的试题版本
- 作文模板等补充资料

资料覆盖 2015 年至 2025 年的多个考试批次；具体内容以仓库当前目录为准，部分资料暂存于“年份待确认”目录中。

```text

```

## 使用方式

### 在线浏览

进入对应的级别、年份和月份目录，选择需要的试题、解析或听力文件即可。GitHub 对 PDF、DOCX 等常见格式提供在线预览；音频文件可以下载后使用播放器打开。

### 下载仓库

```bash
git clone git@github.com:OyamaMeek/CET-question-bank.git
cd CET-question-bank
```

如果使用 HTTPS，也可以执行：

```bash
git clone https://github.com/OyamaMeek/CET-question-bank.git
```

### 推荐练习流程

建议先按照正式考试时间独立完成试题，再结合答案解析定位问题；听力部分可先进行完整套题练习，之后针对错题反复精听。完成复盘后，可以将高频词汇、常见表达和错题整理到自己的笔记中。

## 文件格式说明

| 格式 | 常见用途 |
| --- | --- |
| `.pdf` | 试题、答案、解析及适合打印的版本 |
| `.docx` / `.doc` | 可编辑的试题或答案文档 |
| `.mp3` / `.m4a` | 听力音频 |
| `.png` | 图片版试题或补充资料 |

同一套资料可能存在不同格式、不同版本或重复文件名后缀（例如 `__2`）。使用前请根据文件名和目录确认对应的考试年份、月份与套数。

## 资料整理约定

文件按照以下层级进行整理：

```text
考试级别 / 年份 / 考试月份 / 资料文件
```

其中，`4` 表示 CET-4，`6` 表示 CET-6；月份目录通常使用 `06`、`09` 或 `12` 等形式。暂时无法确认归属年份的资料会放在“年份待确认”目录中，后续可继续补充和归档。

## 贡献方式

欢迎补充缺失的历年真题、答案解析和听力音频，也欢迎协助修正文件归类、统一文件命名或完善目录结构。

提交贡献前，请尽量确认：

1. 文件确实属于 CET-4 或 CET-6 资料，并注明考试年份、月份和套数；
2. 文件名能够清楚表达资料内容，避免使用难以识别的默认名称；
3. 不重复提交已有文件，并尽可能提供清晰、完整、可正常打开的版本；
4. 大文件提交前先确认仓库的存储策略，必要时使用 Git LFS 或其他合适的分发方式；
5. 不要提交个人隐私、恶意文件或与考试资料无关的内容。

推荐的提交流程如下：

```bash
git checkout -b feat/add-cet-materials
# 添加或整理资料
git add CET
git commit -m "docs: add CET materials"
git push origin feat/add-cet-materials
```

随后可以在 GitHub 上创建 Pull Request，说明新增或调整的资料范围。
